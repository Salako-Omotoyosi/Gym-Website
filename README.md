GYM WEBSITE
About the Project
This project is a gym website built with HTML and CSS. It is designed to showcase a fitness center, its services, membership options and its facilities.
Features
*Responsive website layout
*Homepage with a hero section
*About Us section
*Services and fitness programs
*Membership plans
*Contact section
I used VScode (HTML5 & CSS3).  Through this project, I am improving my skills in structuring web pages with HTML, styling layout with CSS, and building user-friendly website interfaces. I look forward to improving, adding JavaScript functionality, adding an interactive membership registration form and improving responsiveness across devices.
