# GYM WEBSITE

A modern gym website built with HTML and CSS to showcase fitness services, membership plans and facilities.

## About the Project

This project is part of my front-end development journey. It focuses on creating an attractive and user-friendly website for a fitness center.

## Features

- Responsive website layout
- Homepage with a hero section
- About Us section
- Services and fitness programs
- Membership plans
- Contact section

## Technologies Used

I used VScode (HTML5 & CSS3).
